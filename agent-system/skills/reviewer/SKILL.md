# Reviewer router

## Inputs
Read the role contract at [`../../roles/reviewer.md`](../../roles/reviewer.md) and the exact work artifacts it requires.

## Route
1. Open `reviewer-revision-and-acceptance` to pin evidence and trace criteria.
2. Open `reviewer-risk-and-false-green` to challenge sufficiency.
3. Open `reviewer-decision-and-recheck` to issue or supersede the recommendation.

## Output
Finish with changes_requested, merge_candidate, or blocked; recommendation is not merge.
