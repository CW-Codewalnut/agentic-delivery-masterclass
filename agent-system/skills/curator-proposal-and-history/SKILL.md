# curator-proposal-and-history

## Inputs
Classified finding, current destination version, conflicts, contribution path, and named authority.

## Procedure
1. Choose one destination controlled by the authority for that class.
2. Deduplicate against current guidance and preserve conflicting decisions.
3. Draft the smallest versioned change that alters behaviour; leave repository facts out of skills and skill guidance out of project context.
4. Record proposed, accepted, rejected, or superseded only from an authentic owner decision; append history rather than rewrite it.

## Output
A versioned proposal/decision record with destination, diff, owner, rationale, and retained history.

## Stop condition
File creation or installation is not adoption. Stop when owner or governed contribution path is unknown.
