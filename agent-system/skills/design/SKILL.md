# Design router

## Inputs
Read the role contract at [`../../roles/design.md`](../../roles/design.md) and the exact work artifacts it requires.

## Route
1. Open `design-input-readiness` first; stop if Design is not required or inputs are blocked.
2. Open `design-state-interaction-spec` for uncovered behaviour.
3. Open `design-source-readiness` for source composition, coverage review, and the exact handoff.

## Output
Finish only with ready, design-not-required, incomplete, conflicting, or blocked status bound to exact revisions.
